Sicherheit, die man sehen kann.

Schluss mit unübersichtlichen Tabellen. YADS ist die moderne Reconnaissance-Platform für Teams, die ihre Attack Surface verstehen, analysieren und absichern wollen. Modular. Skalierbar. Open Source.

Plattform erkunden

Mehr als nur ein Port-Scanner

YADS aggregiert Daten aus verschiedensten Quellen zu einem Single Pane of Glass. Es wurde entwickelt, um die Lücke zwischen manueller Penetration-Testing-Recherche und vollautomatisiertem Vulnerability Management zu schließen. Vom ersten DNS-Request bis zum fertigen Management-Report – alles in einer UI.

🛡️ Die Scanning Engine

Unter der Haube arbeitet ein leistungsstarkes, modulares Framework, das kontinuierlich erweitert wird. Wählen Sie präzise, welche Tests für welches Asset laufen sollen.

CORE Reconnaissance

Die Basis jeder Sicherheitsanalyse. YADS findet, was Sie vergessen haben.

  • Subdomain Enumeration: Passive (CT Logs) & aktive Brute-Force Methoden.
  • DNS Analyse: A, AAAA, MX, TXT, NS Records und Zone Transfers.
  • Port Scanning: TCP/UDP Scans auf die Top 1000 Ports oder Full-Range.

WEB Web Analyzer

Simuliert einen echten User-Besuch mit einem Headless-Browser.

  • Tech Stack Detection: Erkennt CMS, Frameworks (React, Vue), Webserver (Nginx, Apache).
  • Screenshot Engine: Automatische Full-Page Screenshots für visuelle Verifikation.
  • Header Analyse: Prüft Security Headers (HSTS, CSP, X-Frame-Options).
  • API Discovery: Findet Swagger/OpenAPI Specs und GraphQL Endpunkte.

NEU Vulnerability & DAST

Aktive Suche nach bekannten Schwachstellen.

  • Nuclei Integration: Template-basiertes Scannen auf 5000+ CVEs und Misconfigurations.
  • JS SAST: Statische Analyse von Client-Side JavaScript auf Secrets und DOM XSS Sinks.
  • Stealth Mode: Langsame, fragmentierte Scans zur Umgehung von WAFs und IDS.

🕸️ Visualisierung komplexer Daten

Network Graph

In großen Infrastrukturen verliert man schnell den Überblick. Der Network Graph macht Zusammenhänge sofort sichtbar via Force-Directed Graph.

  • Relationship Mapping: Sehen Sie, welche Domains auf derselben IP hosten.
  • Proaktives Clustering: Erkennen Sie Schatten-IT Cluster sofort.
  • Filter: Blenden Sie DNS-Layer aus, um sich auf Web-Verbindungen zu konzentrieren.

🚀 Attack Path Visualization (NEU)

Nicht alle Schwachstellen sind gleich gefährlich. YADS kombiniert Netzwerk-Topologie mit Vulnerability-Daten, um Attack Paths zu visualisieren.

  • Identifizierung kritischer Pfade: Sehen Sie sofort, wie ein Angreifer von einem "low-risk" Asset zu Ihrer Kronjuwelen gelangen könnte.
  • Priorisierung: Fokussieren Sie Ihre Ressourcen auf die Schließung von Pfaden, die echten Schaden anrichten können.

📊 Analytics & Insights

Daten sind gut, Verständnis ist besser. Unsere Analytics-Suite aggregiert Millionen von Datenpunkten zu handlungsrelevanten Informationen.

Geo- & Tech-Intelligence

Wo stehen Ihre Server physikalisch? Welche Länder hosten Ihre kritischen Daten? Das Technology Radar zeigt Ihnen sofort, welche Webserver-Versionen Ihr Netzwerk dominieren.

Dead Links & Hijacking

Finden Sie "tote" Links in Ihren Anwendungen. YADS identifiziert zudem Broken Link Hijacking Kandidaten: Externe Links, die auf nicht mehr existente Domains zeigen und von Angreifern registriert werden können.

🕵️ OSINT Brand Monitoring

Ihre Marke endet nicht auf Ihren eigenen Servern. YADS nutzt die Google Cloud Vision API, um das Internet nach visuellen Kopien Ihrer Logos und Assets zu durchsuchen.

Phishing Detection

Finden Sie betrügerische Seiten, die Ihr Design kopieren, noch bevor eine Domain-Blacklist sie erfasst.

Schatten-Marketing

Entdecken Sie alte Marketing-Landingpages von Agenturen, die nie abgeschaltet wurden.

📑 Reporting & Management

Multi-Tenancy

Ideal für MSPs und Konzerne. Trennen Sie Daten strikt nach Mandanten (Kunden/Abteilungen), behalten Sie aber als Platform-Admin den Gesamtüberblick.

Scheduling & Automation

"Set and Forget". Definieren Sie Scan-Intervalle (Täglich, Wöchentlich) und Compliance-Policies. Lassen Sie YADS arbeiten.

Day/Night Mode

Augenfreundlich. Wechseln Sie nahtlos zwischen Light- und Dark-Mode für lange Analyse-Sessions.

Export Formate

PDF Management Summary: Hochglanz-Reports für das C-Level.
Excel/CSV Raw Data: Vollständige Datensätze für Analysten und Import in SIEM-Systeme.
