    ZIP Package Format

    Um ein neues Add-on zu installieren, erstelle ein ZIP mit folgender Struktur: 

    my_addon.zip
├── module_manifest.json   # Erforderlich: Modul-Metadaten
└── my_addon.py            # Erforderlich: Scanner-Implementierung

    Bundle-Format: Ein Bundle-ZIP enthält mehrere Modul-ZIPs plus eine bundle_manifest.json:

    addon-bundle.zip
├── bundle_manifest.json   # Bundle-Metadaten und Modulliste
├── store_catalog.json     # Optional: Extension Hub Katalog für Offline-Betrieb
└── modules/
    ├── cookie_consent_audit.zip
    └── data_residency_check.zip
    Manifest-Schema anzeigen 
    {
  "module_name":   "my_custom_scanner",
  "label":         "My Custom Scanner",
  "label_de":      "Mein Scanner",
  "module_file":   "my_addon.py",
  "class_name":    "MyCustomScanner",
  "category":      "active",
  "version":       "1.0.0",
  "author":        "Your Name",
  "description":   "Short description.",
  "passive":       true
}
