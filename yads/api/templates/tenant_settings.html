Google Search Integration (OSINT)

Configure your own Google Programmable Search Engine to enable OSINT features independently. These keys are stored securely and used only for your tenant's searches.

How to obtain Keys
  1. Get API Key
    Go to the Google Cloud Console. Create a project, then go to APIs & Services > Credentials > Create Credentials > API Key.
    Make sure to enable the "Custom Search API" in the library.
  2. Get Search Engine ID (CX)
    Go to Programmable Search Engine. Create a new engine, enable "Search the entire web", and copy the "Search engine ID" (CX).
