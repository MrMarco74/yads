Google Search Integration (OSINT)

Configure your own Google Programmable Search Engine to enable OSINT features independently. These keys are stored securely and used only for your tenant's searches.

How to obtain Keys
  1. Get API Key & Enable Vision API
    Go to the Google Cloud Console.
    • Create an API Key under APIs & Services > Credentials.
    • Important: If using "API Restrictions", add "Cloud Vision API" to the allowed list.
    • Go to APIs & Services > Library and enable the "Cloud Vision API".
    • Note: This API requires an active Billing Account (free tier available).
  2. Search Engine ID (CX)
    Optional for Image Search. Used only if you want to use text-based fallback search features in future updates.

From Google Cloud Console (Custom Search API)

From Programmable Search Engine Control Panel

Vulnerability Scanning (Nuclei)

Nuclei is an open-source vulnerability scanner. The API key enables Pro features like cloud-based scanning and team collaboration.

How to get a Nuclei Pro API Key
  1. Go to ProjectDiscovery Cloud Platform (PDCP)
  2. Sign up for a free account or log in
  3. Navigate to Settings → API Keys
  4. Generate a new API key and copy it
Free Tier: Includes basic scanning capabilities. Pro subscription unlocks advanced features, more templates, and higher rate limits.

Get your key from cloud.projectdiscovery.io

Credential Monitoring (Have I Been Pwned)

Check if email addresses associated with your domains have appeared in data breaches.

How to get an HIBP API Key
  1. Go to haveibeenpwned.com/API/Key
  2. Purchase an API key subscription (required for breach lookups)
  3. Copy the API key from your account dashboard
Pricing: HIBP API keys are paid (~$3.50/month). This funds the service and ensures responsible usage. Password hash lookups (k-anonymity) are free and don't require a key.

Get your key from haveibeenpwned.com/API/Key

Social Media Scanner (GitHub & Twitter)

Enhanced reconnaissance for GitHub repositories and Twitter/X mentions.

How to get API Keys
GitHub Personal Access Token
  1. Go to GitHub Settings → Developer settings → Personal access tokens
  2. Click "Generate new token (classic)"
  3. Select scopes: public_repo, read:org, read:user
  4. Generate and copy the token (starts with ghp_)
Free: 5,000 requests/hour with token (vs 60/hour without)
Twitter/X Bearer Token
  1. Go to Twitter Developer Portal
  2. Create a new Project and App
  3. Navigate to "Keys and tokens"
  4. Generate and copy the Bearer Token
Free Tier: 500,000 tweets/month read access. Requires phone number verification.

Get from github.com/settings/tokens

Get from developer.twitter.com

Advanced OSINT Pivots BETA

External threat intelligence APIs for enhanced reconnaissance. These are optional and used for cross-referencing findings.

How to get API Keys
Shodan API Key
  1. Create an account at shodan.io
  2. Go to Account Settings
  3. Copy your API key from the Overview page
Free: Limited search credits. Paid membership ($49 one-time) unlocks full access.
Censys API Key
  1. Create a free account at censys.io
  2. Go to Account → API
  3. Copy both the API ID and Secret (format: API_ID:SECRET)
Free: 250 queries/month for researchers. Enterprise plans available.
VirusTotal API Key
  1. Create an account at virustotal.com
  2. Go to your Profile → API Key
  3. Copy your API key
Free: 500 lookups/day, 4 requests/minute. Premium plans remove limits.
