ZIP Package Format

To install a new scanner module, create a ZIP with the following structure: 

my_module.zip
├── module_manifest.json   # Required: module metadata
└── my_module.py           # Required: scanner implementation

Note: The YADS Module Builder (build_modules_pyz.py) automatically generates compatible ZIP packages with manifests from scanner source files.

Show manifest schema 
{
  "module_name":   "my_custom_scanner",   // unique identifier (snake_case)
  "label":         "My Custom Scanner",
  "label_de":      "Mein Scanner",        // optional German label
  "module_file":   "my_module.py",        // filename in ZIP
  "class_name":    "MyCustomScanner",     // class extending BaseScannerModule
  "category":      "active",              // recon|web|config|exposure|threat|active
  "version":       "1.0.0",
  "author":        "Your Name",
  "description":   "Short description of what this scanner does.",
  "requires_http": false,
  "requires_https": false,
  "default_on":    false,
  "finding_module": true,
  "extractor":     "generic",            // "generic" works for new modules
  "passive":       true                  // true = read-only/safe, false = active probing (shown as badge in UI)
}
