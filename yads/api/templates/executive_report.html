About This Report

This report is generated automatically based on the latest security scans. The security score is calculated as 100 minus weighted deductions per finding severity (Critical −15, High −8, Medium −3, Low −1). Scores are clamped between 0 and 100. Findings are sourced from all active assets in your portfolio. For technical detail, refer to the individual asset scan reports.
