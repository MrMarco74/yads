Prometheus/Grafana Metrics Export

  • Security event monitoring and error tracking panels
  • Target and worker status overview

  • New docker-compose.monitoring.yml overlay
  • Includes Prometheus and Grafana with auto-provisioned datasources
  • One-command deployment: docker compose -f docker-compose.yml -f docker-compose.monitoring.yml up -d
v1.15.0

Release 1.15.0

🔒 Security Audit Logging (MITRE ATT&CK)

  • Comprehensive security event logging aligned with MITRE ATT&CK framework
  • Tracks login/logout events, password changes, MFA events, user management
  • Captures source IP, user agent, tenant context for all events
  • MITRE Tactic and Technique IDs for each event type
  • Database persistence with indexed fields for fast queries

🔌 SIEM Integration

  • Real-time forwarding to Splunk via HTTP Event Collector (HEC)
  • Configurable via SPLUNK_HEC_URL and SPLUNK_HEC_TOKEN environment variables
  • Events enriched with MITRE technique IDs for SOC correlation

🔧 Technical Improvements

  • New SecurityAuditLog database model with proper indexes
  • Security audit module with helper functions for common events
  • Dual logging to database and Splunk for redundancy

v1.14.0

Distributed Worker System

🚀 Major New Feature: Horizontal Scaling

  • Distributed Workers: Deploy YADS workers across multiple Docker Swarm nodes for horizontal scaling.
  • Load Balancing: Automatic task routing to least-loaded workers with capacity.
  • Health Monitoring: Automatic offline detection with task requeuing on worker failure.
  • Resource Quotas: Per-tenant and global limits on concurrent scans and daily quotas.

📊 Unified Logging

  • Aggregated Log View: See logs from all workers in a single real-time view.
  • Tenant Filtering: Filter logs by organization, worker, or log level.
  • Enhanced Metadata: Logs now include tenant and worker information for debugging.

🎛️ Worker Management

  • Settings UI: New "Distributed Workers" section in Settings page.
  • Registration Token: Secure token-based worker authentication.
  • Worker Controls: Suspend, Resume, and Drain workers without restarts.
  • Cluster Statistics: Real-time view of cluster capacity and utilization.

🔧 Technical Improvements

  • New Database Models: WorkerNode, WorkerTask, ResourceQuota tables for distributed state.
  • Worker Client: Worker-side component for manager communication and heartbeats.
  • Docker Swarm: New docker-compose.swarm.yml for multi-node deployments.

Deep Security & Compliance Update

  • Nuclei Vulnerability Integration: Active scanning for 5000+ known vulnerabilities using ProjectDiscovery's Nuclei. Findings are categorized instantly (Critical, High, Medium).
