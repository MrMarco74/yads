v1.20.3Beta

PQC Report, 12 New Scanner Modules, Module Report Center & AI Analytics

A major capability expansion on the path to v2.0. Adds Post-Quantum Cryptography readiness reporting, 12 new security scanner modules, a centralized module report center with per-module PDF/Excel exports, AI-enriched analytics, and significant bug fixes.

🔐 Post-Quantum Cryptography (PQC) Report

  • Dedicated PQC readiness report analyzing all certificates, TLS configurations, and cryptographic primitives across scanned infrastructure.
  • Algorithm classification: quantum-safe (AES-256, SHA-3), quantum-vulnerable (RSA, ECDSA, DH), and transitional status.
  • Per-asset migration risk scoring (Low/Medium/High/Critical) based on algorithm strength, key length, and certificate validity.
  • Aggregate quantum readiness grade (A–F) with executive summary.
  • CBOM (Cryptography Bill of Materials) export in CycloneDX JSON format for NIS2/DORA supply chain compliance.
  • Recommended PQC alternatives per algorithm: CRYSTALS-Kyber, CRYSTALS-Dilithium, SPHINCS+, FALCON.

🔬 12 New Scanner Modules

  • Email Security — SPF, DKIM, DMARC, BIMI analysis with 0–100 score. Detects spoofing-vulnerable and missing enforcement policies.
  • HTTP Security Headers — OWASP-aligned analysis of CSP, HSTS, X-Frame-Options, Referrer-Policy, Permissions-Policy. Per-header scoring with recommendations.
  • Cookie Security Analyzer — Checks Secure, HttpOnly, SameSite flags on all cookies. Detects XSS/CSRF-enabling misconfigurations.
  • CORS Misconfiguration — Tests 4 origin patterns. Identifies permissive cross-origin policies exposing APIs to unauthorized requests.
  • Certificate Domain Mismatch — TLS cert subject/SAN validation against actual domain. Detects mismatch, expired, and self-signed certificates.
  • Threat Intelligence (AbuseIPDB/OTX/VirusTotal) — IP reputation enrichment for all discovered hosts. Aggregate threat score visible in analytics and AI risk scoring.
  • Shodan & Censys Intelligence — Passive host intelligence (ports, banners, CVEs, ASN) without active scanning.
  • JS Secrets Scanner — 25+ secret patterns in JavaScript files: AWS keys, Google API keys, JWTs, Stripe tokens, private keys, and database credentials.
  • Git Exposure Scanner — 49 sensitive path probes (/.git/, /.env, /config.yml, /backup.sql) to detect accidentally exposed repositories and configuration files.
  • Subdomain Takeover Detection — CNAME fingerprinting against 30+ providers (GitHub Pages, Netlify, Vercel, AWS S3, Heroku, Azure, Shopify) to detect dangling DNS records.
  • DNS Zone Transfer (AXFR) — Tests all authoritative nameservers for zone transfer vulnerabilities.
  • Security.txt Validator — RFC 9116 compliant discovery and field validation.

📁 Module Report Center

  • Every scanner module now has a dedicated report page at /reports/module/{name} with configurable columns, PDF export, and Excel export.
  • Specialized templates for DNS, Web Analyzer, Nuclei, Threat Intel, Ports, Deception Detection, and Infrastructure modules.
  • Generic fallback template for all other modules — zero configuration needed for new modules.
  • The central Reports page now shows View, PDF, and Excel buttons for every module in the system.

📊 AI-Enriched Analytics

  • Analytics security-risks endpoint extended to include Threat Intelligence, Nuclei findings, and Port Exposure data.
  • New analytics cards: Threat Intelligence (flagged IPs with scores), Nuclei Findings (critical/high/medium/low distribution + per-target breakdown), Port Exposure (open ports per target).
  • LLM prompt enriched with threat intel flagged IPs, nuclei top targets, and port exposure data for more accurate AI risk assessments.
  • AI risk score now factors in: HTTPS coverage, SSL certificates, open buckets, secrets leaked, hijackable domains, threat intel flags, nuclei findings, and exposed ports.

🐛 Bug Fixes

  • Fixed tenant switch to Platform Admin (no tenant) returning HTTP 422 due to required Form(...) field. Changed to Form(default="").
  • Fixed Broken Link Hijacking empty-state icon being excessively large when no results were found.
  • Removed hardcoded license key from debug script in version control. Replaced with environment variable lookups.
  • Replaced hardcoded dev database password in docker-compose.yml with environment variable substitution.
v1.20.0Beta

AI Intelligence Suite & Advanced Analytics

A major capability release bringing AI-powered security analysis, interactive attack path visualization, executive reporting, and comprehensive finding management to the YADS platform.

🤖 AI Assistant (New Module)

  • AI Finding Prioritization — Automatically ranks all findings for a target by combined exploitability and business impact. Uses OpenAI (gpt-4o-mini) or Anthropic (claude-haiku) when configured (BYOK); falls back to rule-based scoring with keyword boosting otherwise.
  • AI Remediation Assistant — Generates step-by-step, actionable remediation guidance for any selected finding, with effort rating (low/medium/high) and curated reference links. Rule-based fallback covers CORS, XSS, SQL injection, SSL/TLS, HTTP headers, AXFR, cookie security, CSRF, RCE, and open redirect.
  • Natural Language Search — Query your entire findings database in plain English or German (e.g. "show me all high severity SSL issues on api.example.com"). Debounced live search with AI-interpreted or regex-extracted filter chips for severity, module, and domain.
  • AI Multilanguage — All AI-generated outputs (rationale, remediation steps, search interpretation) can be returned in German by passing lang=de. Rule-based fallbacks are fully translated as well.

📊 Executive Report (C-Level Dashboard)

  • Non-technical security summary designed for management and C-level stakeholders.
  • Large grade circle (A–F) with numeric score (0–100), risk trend indicator (improving / stable / deteriorating), and color-coded KPI cards (total assets, critical issues, high-risk issues).
  • Segmented risk distribution bar (critical → info), top 5 risk types with severity badges, top 5 most vulnerable assets, and prioritized recommended actions with plain-language descriptions.
  • Built-in print stylesheet for clean PDF output directly from the browser.

🗺️ Attack Path Visualizer

  • Interactive D3.js force-directed graph showing the full attack surface of any scanned target.
  • Nodes represent: the root host, discovered open ports (color-coded by risk), identified services and technologies (with CVE count), and individual security findings.
  • Directional edges show exploitation chains: high + critical findings are linked with "enables" edges to model multi-step attack paths.
  • Node details panel with type-specific fields, connected nodes list, and filter controls (toggle node types, minimum risk score slider). Top attack paths list allows one-click pan-and-zoom to any node.

📁 Finding Management & Vulnerability Tracking

  • Track the lifecycle of every finding with status labels: Open, Acknowledged, False Positive, Fixed.
  • Add notes to any finding for analyst commentary, remediation timeline, or ticket references.
  • Status filter on the Security Findings page — filter by open, acknowledged, false positive, or fixed.
  • CSV export with all active filters applied (severity, status, module, domain, date range).
  • Finding status is persisted per-tenant, survives re-scans, and is identified by a deterministic SHA-256 hash of domain|module|issue.

🏷️ Asset Tagging & Grouping

  • Assign one or more custom tags to any target (e.g. production, critical, in-scope, cloud).
  • Interactive tag cloud on the Tags page — click any tag to filter the target list to matching assets.
  • Bulk tag operations: select multiple targets and add, remove, or replace their tags in one action.
  • Inline editing: add or remove tags directly from the target list row without navigating away.
  • Manage tags centrally: delete a tag from all targets across the tenant in a single click.

🌐 Multi-Domain Portfolio View (Platform Admin)

  • Platform administrators gain a unified cross-tenant overview table showing per-tenant stats: domain count, critical findings, high findings, average security score, plan tier, and last scan timestamp.
  • Score displayed as a color-coded grade badge (A–F). Expandable sub-rows show the top 3 most vulnerable domains per tenant.
  • Inline search/filter, "View as Tenant" impersonation link, and global KPI cards (total tenants, total domains, critical findings platform-wide).

☁️ Extended Cloud Scanner

  • Added DigitalOcean Spaces (NYC3 + AMS3), Cloudflare R2 storage enumeration.
  • New Shadow IT Detection: probes GitHub Pages, Netlify, Vercel, Heroku, Firebase Hosting, Render, Railway, and Fly.io for active deployments associated with the target domain.
  • Default-page detection filters out false positives (Netlify "not found" pages, Heroku default apps).
  • Cloud scanner now produces structured findings[] with severity ratings — high for open buckets, low for shadow IT — compatible with all reporting and AI analysis modules.

🌍 Multilanguage Exports (EN/DE)

  • All PDF and Excel report exports now accept a ?lang=en or ?lang=de query parameter.
  • German exports translate column headers, section titles, finding labels, status text, and all fixed strings throughout both report types.
  • AI-generated report content (executive summaries, remediation steps) also responds to the language parameter.

⚡ Parallel Scan Execution

  • All independent scanner modules (those without custom dispatch logic) now run concurrently using a ThreadPoolExecutor with up to 6 worker threads per scan.
  • Each parallel module creates its own database session to avoid lock contention.
  • Scan wall-clock time for full multi-module scans significantly reduced on capable hardware.
  • Sequential modules (web analyzer, nuclei, crawler) that depend on ordering are unchanged.
