Product Roadmap

A glimpse into the future of YADS Security Platform.

New Scanner Modules

Feature Description
Enhanced OSINT & Brand Intelligence Improved brand monitoring with deeper web searches, lookalike detection, and reputation tracking across multiple data sources.
Email Intelligence Gatherer Discover email addresses associated with target domains through breach databases, public sources, and pattern analysis.
Social Media Reconnaissance Automated discovery of corporate social media accounts, employee profiles, and brand mentions across major platforms.
🛡️

Deception Technology Detection

A new detection module that identifies defensive deception infrastructure with confidence scoring. Each detection includes a confidence score and risk rating to help assess the target environment.

Capability Description
Honeypot Detection Identify web and service-level honeypots through behavioral analysis and fingerprinting techniques.
DNS Sinkhole Identification Detect domains redirected to sinkhole infrastructure, commonly used by security teams and ISPs.
Tarpit Recognition Identify network tarpits designed to slow down attackers and automated scanning tools.
⚙️

Platform Improvements

Feature Description
Proxy Support (Zscaler, etc.) Configure HTTP/HTTPS proxy settings for all scanner modules (except Nmap). Essential for enterprise environments using security gateways like Zscaler, Netskope, or corporate proxies.
Custom TLS Certificates Support for custom CA certificates and client certificates for scanning internal infrastructure behind corporate PKI.
One-Click Updates In-app update mechanism that pulls the latest Docker image and performs a graceful restart without manual intervention.
Enhanced Logging & SIEM Structured logging with MITRE ATT&CK event tagging, improved Splunk integration, and syslog forwarding for comprehensive audit trails.
Tenant-Aware Workers Assign dedicated worker nodes to specific tenants or configure them as shared resources for flexible multi-tenant deployments.
System Administration Dashboard Central view of all workers, active tasks, queue depth, and real-time resource metrics (CPU, RAM, Network).
Storage Analytics Monitor disk usage across screenshot folders and scan artifacts with cleanup recommendations.
Prometheus/Grafana Export Native metrics endpoint for infrastructure monitoring, alerting integration, and performance dashboards.

Automation & Integrations

Integration Description
Jira Automatically create and update issues based on scan findings, with customizable severity mapping and project assignment.

Cortex XSOAR Bi-directional integration for SOAR playbook orchestration, automated response, and incident enrichment.
