Post-Quantum Cryptography (PQC) Available

A dedicated PQC readiness report that analyzes all cryptographic assets across your infrastructure and assesses quantum-safe migration status. Generates a Cryptography Bill of Materials (CBOM) in CycloneDX format — aligned with NIS2, DORA, and BSI TR-02102 guidance.

Feature Description
PQC Readiness Report Available Scans all certificates, TLS configurations, and cryptographic primitives. Classifies algorithms as quantum-safe, quantum-vulnerable, or transitional. Prioritized migration list with algorithm details (RSA, ECDSA, AES, etc.) and recommended PQC alternatives (CRYSTALS-Kyber, CRYSTALS-Dilithium, SPHINCS+).
CBOM (CycloneDX) Export Available Generates a Cryptography Bill of Materials in CycloneDX JSON format. Lists all cryptographic components with algorithm, key length, usage context, and quantum vulnerability rating. Required for NIS2/DORA supply chain security reporting.
Migration Risk Scoring Available Each asset receives a quantum migration risk score (Low/Medium/High/Critical) based on algorithm strength, key length, certificate validity period, and exposure level. Executive summary with aggregate quantum readiness grade (A–F).

AI Intelligence Suite Available

A complete AI-powered security analysis layer built directly into YADS. Uses your own OpenAI or Anthropic API key (BYOK model) with intelligent rule-based fallbacks when no AI key is configured. All outputs are available in English and German.

Feature Description
AI Finding Prioritization Available Ranks all findings for a target by exploitability and business impact. Supports OpenAI (gpt-4o-mini) and Anthropic (claude-haiku-4-5) with per-tenant BYOK. Includes a rule-based fallback using severity scores and keyword boosting (RCE, SSRF, injection, XSS, etc.) when no AI key is configured.
AI Remediation Assistant Available Generates step-by-step remediation guidance for any selected finding with effort estimation (low/medium/high) and reference URLs. Rule-based fallback covers 10+ vulnerability classes: CORS, XSS, SQL injection, SSL/TLS, HTTP headers, DNS zone transfer, cookie security, CSRF, RCE, and open redirect.
Natural Language Search Available Query findings across all monitored assets in plain English or German. Examples: "critical nuclei findings on staging.example.com", "all high severity SSL issues", "email security problems this month". Live search with 500ms debounce, AI-parsed or regex-extracted filter chips (severity, module, domain).
AI Multilanguage Output Available All AI endpoints accept a lang=de parameter. AI-generated rationale, remediation steps, and search interpretations are returned in German. Rule-based fallbacks are also fully translated, including effort labels and rationale strings.

Executive & Portfolio Reporting Available

New high-level views for security management, C-level reporting, and cross-tenant visibility for platform administrators.

Feature Description
Executive Report (C-Level) Available Non-technical security summary with: grade circle (A–F), numeric score (0–100), risk trend (improving/stable/deteriorating), KPI cards, segmented risk distribution bar, top 5 risk types, top 5 vulnerable assets, and prioritized recommended actions. Includes a print stylesheet for immediate PDF output.
Attack Path Visualizer Available D3.js force-directed graph showing the attack surface of any scanned target. Nodes: host, open ports (risk-colored), services/technologies (with CVE counts), and findings. Directed edges model exploitation chains between high/critical findings. Zoom/pan, draggable layout, one-click attack-path navigation, and filter controls.
Multi-Domain Portfolio View Available Platform-admin view with cross-tenant statistics: domain count, critical/high findings, average security score (A–F grade badge), plan tier, last scan. Expandable rows reveal top 3 vulnerable domains per tenant. Includes global KPI cards and "View as Tenant" impersonation link.
Multilanguage PDF & Excel Exports Available All exports now accept ?lang=en or ?lang=de. German exports translate column headers, section titles, finding labels, and all fixed strings in both PDF and Excel formats.

Finding Management & Asset Organization Available

Tools to track the full remediation lifecycle of security findings and organize assets for better operational visibility.

Feature Description
Finding Status Tracking Available Track the lifecycle of each finding with four states: Open, Acknowledged, False Positive, Fixed. Add analyst notes per finding. Status survives re-scans and is identified by a deterministic hash of domain|module|issue. Color-coded badges and a status filter on the Security Findings page.
Findings CSV Export Available Export all findings to CSV with full filter support (severity, status, module, domain, date range). Columns: domain, title, severity, module, status, found_at, notes.
Asset Tagging & Grouping UI Available Assign custom tags to targets (e.g. production, cloud, in-scope). Interactive tag cloud for filtering, inline tag editing per target, bulk tag operations (add/remove/replace across multiple targets), and central tag management with one-click delete across the tenant.
Extended Cloud Scanner Available Added DigitalOcean Spaces (NYC3 + AMS3), Cloudflare R2. New Shadow IT detection across GitHub Pages, Netlify, Vercel, Heroku, Firebase Hosting, Render, Railway, and Fly.io — with false-positive filtering for default platform pages. Findings now include structured severity ratings compatible with AI analysis.

New Scanner Modules Available

Module Description
Email Security Available SPF, DKIM, DMARC, and BIMI analysis. Checks email authentication configuration and scores the domain's email security posture (0–100). Detects spoofing-vulnerable configurations and missing DMARC enforcement policies.
HTTP Security Headers Available OWASP-aligned analysis of all security response headers: Content-Security-Policy, HSTS, X-Frame-Options, Referrer-Policy, Permissions-Policy. Per-header scoring with remediation recommendations.
Cookie Security Analyzer Available Checks all cookies for Secure, HttpOnly, and SameSite flags. Detects session cookie misconfigurations, overly broad domain scope, and missing attributes that could enable XSS or CSRF attacks.
CORS Misconfiguration Available Tests 4 CORS origin patterns (null, wildcard, subdomain, arbitrary). Detects permissive cross-origin policies that expose APIs to unauthorized cross-site requests.
Certificate Domain Mismatch Available Verifies TLS certificate subject/SAN fields match the actual domain. Detects mismatch, expired, or self-signed certificates that would trigger browser security warnings.
Threat Intelligence (AbuseIPDB/OTX/VT) Available Enriches all discovered IPs with reputation data from AbuseIPDB, AlienVault OTX, and VirusTotal. Aggregate threat score, flagged-by count, and malware/phishing/botnet classification. Appears in analytics view and AI risk scoring.
Shodan & Censys Intelligence Available Host intelligence from Shodan and Censys — open ports, banners, CVEs, and ASN data without active scanning. Provides passive reconnaissance data for all targets.
JS Secrets Scanner Available Scans all JavaScript files loaded by the target for 25+ secret patterns: API keys (AWS, Google, Stripe, Twilio), JWTs, private keys, database credentials, and custom regex patterns.
Git Exposure Scanner Available Probes 49 sensitive paths including /.git/, /.env, /config.yml, /backup.sql, and similar. Detects accidentally exposed source code repositories, configuration files, and backup archives.
Subdomain Takeover Detection Available Checks CNAME chains against 30+ provider fingerprints (GitHub Pages, Netlify, Vercel, AWS S3, Heroku, Azure, Shopify, etc.). Identifies dangling DNS records that could be hijacked.
DNS Zone Transfer (AXFR) Available Tests all authoritative nameservers for zone transfer vulnerabilities. Successful AXFR exposes the complete DNS zone — a high-impact information disclosure finding.
Security.txt Validator Available RFC 9116 compliant security.txt discovery and validation. Checks for required fields (Contact, Expires), optional fields (Encryption, Policy), and correct file placement at /.well-known/security.txt.
Enhanced OSINT & Brand Intelligence Available Improved brand monitoring with deeper web searches, lookalike domain detection (homoglyphs, bitsquatting, combosquatting), PhishTank/URLhaus integration, and reputation scoring across multiple data sources.

Deception Technology Detection Available

A new detection module that identifies defensive deception infrastructure with confidence scoring (0-100) and risk ratings (low/medium/high/critical). Helps assess whether a target environment includes honeypots, sinkholes, or other deception technologies.

Capability Description
Honeypot Detection Available Identify web honeypots (Glastopf, SNARE, Cowrie), SSH honeypots (Cowrie, Kippo), and service honeypots (Dionaea, Mailoney) through behavioral analysis, banner fingerprinting, and response pattern matching.
DNS Sinkhole Identification Available Detect domains redirected to sinkhole infrastructure using a database of known sinkhole IPs (Spamhaus, Microsoft DCU, Shadowserver), ASN matching, and landing page analysis.
Tarpit Recognition Available Identify HTTP, SMTP, and TCP tarpits through timing analysis, detecting slow responses, trickling data, and deliberate connection delays designed to slow down scanners.

Platform Improvements

All UI elements, navigation, scan result labels, PDF reports, Excel exports, and AI-generated outputs are available in both languages. Custom TLS Certificates Available Support for custom CA certificates and client certificates (mTLS) for scanning internal infrastructure behind corporate PKI. Includes HTTPS-only mode with environment variable override for emergency fallback.
One-Click Updates Available In-app update mechanism that pulls the latest Docker image and performs a graceful restart without manual intervention. Includes automatic queue pause, task drain, and zero-downtime updates.
Enhanced Logging & SIEM Available Structured logging with Splunk integration, unified log viewer with tenant filtering, real-time log streaming, and comprehensive audit trails for all scan activities.
Security Audit Logging (MITRE ATT&CK) Available Comprehensive security event logging aligned with MITRE ATT&CK framework. Tracks login/logout events, password changes, MFA events, user management, role changes, and tenant switches. Includes IP address, user agent, and MITRE technique IDs for SIEM correlation.
Tenant-Aware Workers Available Assign dedicated worker nodes to specific tenants with per-tenant resource quotas (concurrent scans, daily limits, network throughput). Full worker registration, heartbeat monitoring, and suspend/drain operations.
System Administration Dashboard Available Central view of all workers with real-time status, cluster statistics (active workers, capacity, utilization), task queue depth, and worker management (suspend, resume, drain, remove).
Storage Analytics Available Monitor disk usage across screenshot folders, logs, backups, and scan artifacts. Includes cleanup recommendations and one-click actions to delete old files, compress logs, and prune backups.
Prometheus/Grafana Export Available Native metrics endpoint for infrastructure monitoring, alerting integration, and performance dashboards.
Software & Crypto BOM Available CycloneDX-format Software Bill of Materials (SBOM) and Cryptography Bill of Materials (CBOM) for supply chain security, NIS2/DORA compliance, and post-quantum readiness assessment.

Identity Provider & SSO Integration Planned

Enterprise-grade authentication via external identity providers. Allows organizations to use existing corporate identity infrastructure for YADS login, eliminating the need for separate user management and enabling centralized access control.

Feature Description
Azure AD / Entra ID Planned OAuth2/OIDC integration with Microsoft Azure Active Directory (now Entra ID). Users log in with their corporate Microsoft account. Supports tenant-scoped app registrations, group-based role mapping (admin/scanner/auditor), and conditional access policies.
SAML 2.0 (Generic) Planned SAML 2.0 Service Provider support for compatibility with Okta, Ping Identity, ADFS, Keycloak, and other enterprise IdPs. Configurable attribute mapping for username, email, and role claims.
OIDC (Generic) Planned Generic OpenID Connect provider support. Works with Google Workspace, GitHub Enterprise, GitLab, and any standards-compliant IdP. Per-tenant IdP configuration for multi-tenant deployments.
Group-based Role Mapping Planned Automatically assign YADS roles (admin, tenant_admin, scanner, auditor) based on IdP group membership. No manual user provisioning required — access is fully driven by corporate directory groups.
