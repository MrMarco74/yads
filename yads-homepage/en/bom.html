Supply Chain Transparency

YADS provides comprehensive Bill of Materials (BOM) documentation to support your software supply chain security requirements. All BOMs are generated in CycloneDX format, an OWASP standard for software composition analysis.

These documents are essential for compliance with regulations such as NIS2, DORA, and Executive Order 14028.

Software Bill of Materials (SBOM) CycloneDX JSON

Complete inventory of all software components, libraries, and dependencies used in YADS. Includes version information, license data, and package URLs (purl) for vulnerability tracking.

Updated with each release | Generated with Syft

Contents: Python packages, system libraries, container base image components, and transitive dependencies.

Cryptography Bill of Materials (CBOM) CycloneDX JSON

Comprehensive inventory of all cryptographic algorithms, protocols, and implementations used in YADS. Essential for post-quantum cryptography migration planning and cryptographic agility assessments.

Contents: TLS configurations, hash algorithms, encryption ciphers, key exchange protocols, digital signatures, and certificate handling.

Using the BOMs

Vulnerability Scanning

Import the SBOM into vulnerability scanners like Grype, Trivy, or OWASP Dependency-Track:

grype sbom:sbom.json

License Compliance

The SBOM includes license information for all components, enabling automated license compliance checks.

Cryptographic Inventory

Use the CBOM to assess your cryptographic posture and plan for post-quantum cryptography migration.
