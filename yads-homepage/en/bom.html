2. External Tools & Binaries

These tools are invoked by YADS as external processes (not linked as libraries). They must be installed separately. Copyleft licenses do not propagate to YADS because no source code is incorporated.

Nmap Network Scanner GPL-2.0 Not Bundled

Copyright © 1996–2024 Insecure.Com LLC. Used for stealth port scanning (nmap_scanner module).

License note: Nmap is licensed under the GNU General Public License v2.0 with a special exception. YADS does not bundle Nmap — it must be installed separately by the system administrator. Invoking Nmap as an external subprocess does not impose GPL obligations on YADS itself. If you redistribute YADS together with Nmap (e.g. in a custom Docker image), the GPL requires you to provide access to Nmap's source code or a written offer to do so.

Install Nmap:

# Debian / Ubuntu
apt-get install -y nmap

# RHEL / CentOS / Rocky
yum install -y nmap

# Or via YADS Admin UI: Settings → Scanner Resources → Install nmap

If Nmap is not installed, the nmap_scanner module is automatically disabled in the YADS scan type selector. All other scan modules continue to work without Nmap.

Source: nmap.org/book/man-legal.html

Valkey BSD 3-Clause

Copyright © The Valkey Contributors. Used as message broker and result backend for the Celery task queue. Valkey is a BSD-licensed fork of Redis 7.2 maintained by the Linux Foundation.

License note: Valkey is licensed under BSD 3-Clause — fully permissive, no copyleft, no SSPL restrictions. The redis-py client library (MIT) is wire-compatible with Valkey and requires no changes. YADS migrated from Redis 7 (SSPL) to Valkey 8 to eliminate any licensing concerns for commercial deployments.

4. Compliance Notes

Commercial Distribution

All MIT, BSD, Apache 2.0, and PostgreSQL-licensed components may be used in commercial products without restriction, provided copyright notices are retained. YADS ships a NOTICE file with every release covering all attribution requirements.

Nmap & GPL

Nmap is not bundled with YADS. It is installed from OS package repositories as an optional dependency. Subprocess invocation does not create a "derived work" under GPL-2.0, preserving license independence.

Valkey (BSD) instead of Redis (SSPL)

YADS uses Valkey 8 (BSD 3-Clause) as a fully permissive drop-in replacement for Redis. No SSPL obligations apply to any deployment scenario.

No AGPL / GPL Contamination

No AGPL or GPL-licensed library is imported into the YADS Python codebase. Copyleft exposure is limited to the Nmap subprocess dependency described above.
