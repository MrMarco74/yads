Support & Installation

Everything you need to install, configure, and run YADS.

1. Release Download

Download the latest release package. It contains all Docker images, configuration templates, and documentation for offline installation.

Download v1.11.0 (.zip)
SHA256: 7c8b53f9c5adab9385a48c139ec496e43513623e6cf9c31d7b834bcf5a496ba8

2. Installation Guide (Docker)

Prerequisites

  • Docker Engine (v20.10+)
  • Docker Compose (v2.0+)
  • License Key (sent via email)

Step 1: Load Images

Unzip the archive and load the Docker images:

docker load < yads-images.tar.gz

Verification:

docker images | grep yads # Should list yads-api and yads-worker

Step 2: Configuration

Create a .env file in the same directory as docker-compose.yml:

# .env File # --- Database --- POSTGRES_PASSWORD=secure_password_here # --- Security --- SECRET_KEY=random_string_here

Note: You will configure the license key via the web interface later.

3. Start & License

Run docker compose up -d.

After startup, log in and navigate to Settings > System Settings > License Management to enter your key.

Default Login: admin / admin (Change immediately!)

3. Technical Architecture

YADS is built on a microservices architecture, orchestrated by Docker Compose.

yads-api

Backend (FastAPI). Manages data, users, and API.

yads-worker

Background Service. Executes scans (Nuclei, Nmap, Chrome).

PostgreSQL

Primary database for persistence.

Redis

Task Queue & Caching Layer.
