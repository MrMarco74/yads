v1.13.3

Kritischer Template-Fix

🐛 Kritische Fehlerbehebungen

  • Target Detail Seite: Fehler 'dict object has no attribute response_headers' behoben, der 500-Fehler beim Anzeigen von Target-Details verursachte.
  • HTTP Traffic Modal: Null-Checks für fehlende request_headers und response_headers Daten hinzugefügt.
  • Exception Handling: Verbesserte Fehlerprotokollierung mit vollständigen Tracebacks für besseres Debugging von Template-Rendering-Problemen.

🔧 Technische Verbesserungen

  • Template-Sicherheit: Verbesserte Jinja2-Template-Robustheit mit defensiven Null-Checks für optionale Dictionary-Felder.
  • Fehler-Sichtbarkeit: Generischer Exception-Handler hinzugefügt, um unbehandelte Exceptions mit vollständigen Stack-Traces zu erfassen.
v1.13.2

Multi-Tenancy & Performance Update

🛡️ Multi-Tenancy Improvements

  • Queue Isolation: Jeder Tenant sieht nur seine eigenen Tasks in der Warteschlange.
  • Tenant-scoped Purge: "Queue Purge" löscht nur Tasks des eigenen Tenants, ohne andere zu beeinflussen.

⚡ Performance-Optimierungen

  • Network Graph Limit: Neue max_nodes Begrenzung verhindert Browser-Abstürze bei großen Datensätzen.
  • UI Slider: "Max Targets" Regler zur Anpassung der Knotenzahl (100-2000).
  • Truncation Warning: Warnung wenn nicht alle Daten angezeigt werden.

🖼️ Server-Side Graph Rendering

  • Full Graph Image: Neuer Button für serverseitige Bildgenerierung mit NetworkX/matplotlib.
  • 100k+ Nodes: Ermöglicht Visualisierung sehr großer Infrastrukturen als statisches PNG.
  • Loading Indicator: "Please wait"-Anzeige während des Server-Renderings.

v1.5.0

Deep Security & Compliance Update

🚀 Deep Security Features

  • Nuclei Vulnerability Integration: Active scanning for 5000+ known vulnerabilities using ProjectDiscovery's Nuclei. Findings are categorized instantly (Critical, High, Medium).
  • Stealth Nmap Scan: New "Stealth" option using evasion flags (-sS, -T2, -D RND:5) for undetectable port scanning.
  • JS SAST Analysis: Static Analysis of client-side JavaScript to detect DOM XSS sinks (innerHTML, eval) and hidden API routes.

📊 Reporting & Compliance

  • Security Grade Mapping: Aggregates all scan data into an A-F Grade with clear risk factor deductions.
  • Compliance Dashboard: Automatically maps findings to standards like OWASP Top 10 and GDPR/ISO27001.
  • Swagger/OpenAPI Parser: Automatically detects and displays API endpoints from swagger.json files.
